Formation

Form an entity in five steps

This is the order Charter House uses for a limited liability company. Other entity types follow the same order, with their own papers.

01

Choose the name

The name must be different from the names already on the state register, and it must carry the ending the state requires, such as LLC. We check the register before we file, so the name is not refused for a conflict we could have seen.

02

Choose the state

An entity is formed in one state. That state holds its papers and sets its due dates. The state where the entity does its work may need a second registration, which is a separate filing.

03

Name the agent

The registered agent receives legal papers and state notices for the entity. The agent must have an address in the state of formation. Charter House can act as the agent of record for the entities it forms.

04

File the articles

The Articles of Organization are the formation filing. They list the name, the agent, the organizer and the address of the entity. The state's filed copy goes into the entity record.

05

Get the EIN

Once the entity exists, it applies for its federal employer identification number. The number goes into the entity record. Banks and payroll providers ask for it, so get it before opening accounts.

Before you start
Have the entity's name, the state, the members or organizer, and the address for the agent. We do not need a password or bank detail to form an entity.
